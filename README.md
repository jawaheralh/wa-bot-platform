# منصة بوت واتساب — نظام وحدات متعدد المنشآت

بوت واتساب ذكي يخدم عدة منشآت في تشغيل واحد. كل منشأة لها رقمها وإعداداتها
وقاعدة معرفتها، والوظائف مقسّمة إلى **وحدات** تُفعَّل لكل منشأة على حدة من
صفحة الأدمن.

قيد الإنشاء — المرحلة الأولى: النواة ونظام الوحدات ومزوّد Baileys.

## التشغيل

```bash
npm install
cp .env.example .env     # ثم املئي SESSION_SECRET و ANTHROPIC_API_KEY
npm run seed             # منشأتان تجريبيتان + أدمن النظام
npm start
npm test
```
